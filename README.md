# 🎬 Script2Video AI

An AI-powered tool that converts text scripts into videos with AI voice, background images, and music.

**Built by:** Abdul Nafeue Babar

---

## ✨ Features

- 📝 **Text to Voice** — gTTS (Urdu, English, Hindi)
- 🖼️ **Background Images** — Custom images ya AI-generated
- 🎵 **Background Music** — Music library se choose karo
- 🎥 **Video Generation** — MoviePy se complete video
- 🎨 **Custom Styles** — Color, gradient, images
- 📱 **Web Interface** — Browser se use karo
- 💾 **Video History** — Purane videos save rahenge

---

## 🛠️ Tech Stack

| Layer | Technology |
|-------|------------|
| Language | Python 3.13 |
| Voice | gTTS |
| Video | MoviePy |
| Images | Pillow (PIL) |
| Web | Flask |
| Database | SQLite |
